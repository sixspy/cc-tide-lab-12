# 潮切

中文名：**潮切** · 前缀 `tide` · 端口 **7900**

## 骨架（新骨，不是闸对/对拍/缝包换皮）

**观测点装载 → 事件时入窗缓冲 → 关窗物化切片 → 迟到/乱序旁路 → 窗账与缓冲互证**

| 对比 | 闸对 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→开腿→成对 | 双轨装载→键对齐 | **单流入→入窗缓冲→关窗物化** |
| 在途 | 开腿账 | 悬账单（对齐后） | **入窗缓冲（未关窗）** |
| 产物 | 行程账 | 对齐差+结论 | **窗切片账** |
| 旁路 | 旁路匣 | 悬账/缺边 | **迟到匣（事件时出窗）** |

皮：物流网点运单轨迹上报。去皮：**事件时关窗管道 + 缓冲 + 迟到旁路 + 窗贯验**。  
禁止做成运单 CRUD、配送看板、工单系统。禁止抄闸对开腿/对拍左右轨命名。

## 切片键契约（已实现 · 形态二 双写两轨）

关窗入库管道上的键契约编排，落在 `backend/app/modules/切片键契约/`：

- **现行轨**：装载时把当时契约的版本/指纹钉进缓冲行；关窗在同一写事务里读同一契约快照，
  校验与写片同成败。指纹一致才按契约模板出片，切片编号必含窗号+运单键，并落票指纹。
- **归档轨**：缺键 / 过期契约 / 契约混票 → 整票进 `切片归档`（归档键+拒因），现行不涨；
  两轨读引用不同（现行读 切片编号+契约指纹，归档读 归档键+拒因）。
- **并发**：声明契约与关窗共用 `db.写事务`（进程内写锁 + `BEGIN IMMEDIATE`），过期键不得进现行。
- **只读接口**：`GET /api/切片键契约`（策略名/契约版/指纹/拒因/归档键/形态标记/valid），
  `POST /api/切片键契约/声明`，`GET /api/切片归档`。
- **贯验协同**：`窗贯验/跑` 加归档事件互证与切片键检查（含窗号+运单键、契约/票指纹同票）。
- **夹具**：`切片键新契约样例`（新契约成片）、`切片键过期样例`（过期整票归档，现行不涨）。
- **测试**：`backend/tests/test_切片键契约.py`（先红后绿），`python3 -m pytest tests/`。
